# Subham Datta — Personal Portfolio

A responsive personal portfolio website prepared for Oasis Infobyte Web Development & Designing, Level 1 Task 2.

## Sections
- Hero/profile and role statement
- About Me
- Technical skills
- Project cards for ZELORA, CareerPortal, and VoidWear
- Experience and education timeline
- Contact links and footer

## Tech stack
- HTML5
- CSS3 (Grid, Flexbox, responsive media queries)
- Vanilla JavaScript for mobile navigation and smooth scrolling
- Google Fonts

## Before publishing
1. Replace `subham@example.com` with your real professional email.
2. Replace placeholder GitHub links with the exact repository links for ZELORA and VoidWear.
3. Confirm that the internship title, dates, and responsibilities match your official records before keeping the Oasis Infobyte timeline entry public.
4. Check all external links and capture desktop/mobile screenshots.

## Run locally
Open `index.html` in a browser.

## Note
The page uses a typographic monogram rather than a fabricated personal photograph. Project descriptions are summaries and should be edited to reflect the current, verifiable state of each project.
