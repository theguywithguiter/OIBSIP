# NOVA — Product Landing Page

A responsive concept landing page created for the Oasis Infobyte Web Development & Designing internship, Level 1 Task 1.

## Features
- Sticky navigation and responsive mobile menu
- Hero section with CTA
- Features, story/about, testimonials, and footer sections
- Consistent palette and typography
- Responsive CSS Grid/Flexbox layouts
- Semantic HTML and accessible navigation labels

## Tech stack
- HTML5
- CSS3
- Small vanilla JavaScript snippet for the mobile navigation

## Run locally
Open `index.html` in a browser. An internet connection is used for Google Fonts; system fallbacks are provided.
